# Задание 4. Чеклист и инструкция по сдаче

## ✅ Проверка по требованиям ревьюера (всё учтено)

### Участники (8 шт.) ✅
- Управляющий магазином
- Управляющий офисом
- Специалист HR
- UI (Сервисные работы)
- API (Сервисные работы)
- БД (Сервисные работы)
- Сервис интеграции
- Система «Персонал»

### Блоки диаграммы ✅

| Блок | Содержание |
|------|------------|
| **Аутентификация** | POST /auth/login → SELECT FROM Users (email, password_hash); проверка role → 200 OK (token, role) |
| **Создание задания** | Форма → POST /tasks → Валидация параметров → INSERT ServiceTask → UPDATE status="в работе" → 201 Created |
| **Подбор специалистов** | GET /tasks/{id}/specialists → Сервис интеграции → Система Персонал → specialists[] → 200 OK |
| **alt [найдены]** | POST /tasks/{id}/assign → INSERT TaskAssignment → UPDATE "выполнен" → подтверждение |
| **alt [не найдены]** | POST /recruitment-requests → INSERT RecruitmentRequest → передача HR → HR добавляет кандидатов → уведомление |
| **Завершение** | PATCH /tasks/{id}/status ("закрыт") → UPDATE → "Задание закрыто" |

### Замечания ревьюера — исправлены ✅

2. ✅ Специалист HR выполняет действия (обработка заявки, добавление кандидатов)
3. ✅ Система «Сервисные работы» разбита на UI, API, БД
4. ✅ Есть аутентификация с проверкой role
5. ✅ Ответ со статусом при создании (201 Created, status="в работе")
6. ✅ Валидация на бэкенде при создании и при подборе

## Как сдать задание на платформе

1. **Войди** на [practicum.yandex.ru](https://practicum.yandex.ru) под своей учётной записью.

2. **Открой свой курс** «Осуществление интеграции программных модулей» (MCRPO).

3. **Перейди к Заданию 4** — урок «Работа над проектом» или «Задания 1–4», блок с заданием 4 (диаграмма последовательности).

4. **Нажми кнопку «ОК»** (подтвердить готовность).

5. **Загрузи файл:**
   - Файл: `Задание 4. Диаграмма последовательности (sequence).drawio`
   - Путь: `Сдача_ревьюеру/Задание 4. Диаграмма последовательности (sequence).drawio`
   - Либо выбери файл из папки проекта на компьютере.

6. **Нажми «Загрузить результат»** внизу страницы.

7. **Проверка:** результат будет на странице работы. Комментарии ревьюера появятся там же (или скачай файл с комментариями, если так устроено в курсе).

### Важно

- Задания 1–4 сдаются **единым комплектом** — один пакет на ревью. Если задание 4 сдаётся отдельно, загрузи только файл диаграммы.
- Если в интерфейсе есть поле для нескольких файлов — загрузи все артефакты заданий 1–4 (US, BPMN, ER, Sequence) по инструкциям платформы.
- Уточни у куратора, сдаётся ли весь проект одним архивом или каждый артефакт отдельно.
