# Задание 5. Исправление ошибок в JSON

## Что сделано

Сверил JSON с эталоном из урока (таблицы users, shops, tasks и т.д.). Нашёл 3 ошибки и поправил запрос.

## Исходный вариант

```json
{
  "tasks": [
    {
      "id": 1,
      "title": "Провести инвентаризацию торгового зала",
      "descripton": "Проверка остатков по полкам",
      "start_date": "2025-09-22",
      "end_date": "2025-09-20",
      "requirements": "Исполнитель со знанием складского учёта",
      "status": "новый",
      "created_by": 1,
      "location_id": 1
    }
  ]
}
```

## Ошибки

**1. Опечатка в descripton.** Пропущена буква i — должно быть description. В эталоне так и указано.

**2. location_id.** В эталоне связь с магазином идёт через shop_id (FK на shops.id). location_id нет в схеме — заменил на shop_id.

**3. Даты перепутаны.** end_date стоит 20.09, start_date — 22.09, то есть окончание раньше начала. Поменял местами: старт 20.09, конец 22.09.

## Исправленный JSON

```json
{
  "tasks": [
    {
      "id": 1,
      "title": "Провести инвентаризацию торгового зала",
      "description": "Проверка остатков по полкам",
      "start_date": "2025-09-20",
      "end_date": "2025-09-22",
      "requirements": "Исполнитель со знанием складского учёта",
      "status": "новый",
      "created_by": 1,
      "shop_id": 1
    }
  ]
}
```
