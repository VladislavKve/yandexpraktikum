# Как сдать работу на Яндекс Практикум

## Способ сдачи: Яндекс Диск

По инструкциям курса артефакты загружаются на **Яндекс Диск**, а не через форму на сайте.

### Шаги

1. **Создай папку** на Яндекс Диске (например: «Проект MCRPO — задания 1–5»).

2. **Загрузи все артефакты** в эту папку.

3. **Открой доступ по ссылке**
   - Правый клик по папке → «Поделиться» / «Публичная ссылка»
   - Убедись, что ссылка доступна **без запроса разрешения** (для просмотра).

4. **Скопируй ссылку** на папку.

5. **Перейди на practicum.yandex.ru** в урок «Работа над проектом. Задание 5» (или в урок с финальным ревью).

6. **Вставь ссылку** в поле для отправки и отправь работу.

7. **Перед отправкой проверь:**
   - Все нужные файлы в папке
   - Файлы открываются и читаются
   - Ссылка работает без запроса разрешения

> ⚠️ Если хотя бы один файл не откроется или доступ закрыт — работа вернётся на доработку (это считается одной итерацией).

## Форматы и состав пакета

### Финальный пакет (задания 1–5)

| Задание | Артефакт | Формат |
|---------|----------|--------|
| **1** | Пользовательские истории | .docx / .pdf (Word, Google Docs, Яндекс Документы) |
| **2** | BPMN-схема | .drawio |
| **2** | Легенда диаграммы | .docx (если отдельно) |
| **3** | ER-диаграмма | .drawio или .png / .svg |
| **4** | Диаграмма последовательности | .drawio |
| **5** | Исходный JSON | .json |
| **5** | Исправленный JSON | .json |
| **5** | Описание ошибок | .md или .docx |

### Файлы в папке `Сдача_ревьюеру`

| Файл | Назначение |
|------|------------|
| `Задание 2. Процесс выполнения сервисных работ...drawio` | BPMN |
| `Задание 3. ER-диаграмма.drawio` | ER |
| `Задание 4. Диаграмма последовательности (sequence).drawio` | Sequence |
| `Задание_5_JSON_запрос.json` | Исходный JSON |
| `Задание_5_JSON_запрос_исправленный.json` | Исправленный JSON |
| `Задание_5_описание_ошибок.md` | Описание найденных ошибок |

### Что ещё нужно добавить

- **Задание 1 (US):** файл `.docx` с пользовательскими историями (если он лежит в другой папке — скопируй в папку для сдачи).
- **Задание 2 (легенда):** если легенда в отдельном файле — добавь его в папку.

## Структура папки для загрузки на Диск

```
Проект MCRPO/
├── Задание 1. Пользовательские истории (US).docx
├── Задание 2. Процесс...drawio
├── Легенда диаграммы.docx          (если есть)
├── Задание 3. ER-диаграмма.drawio
├── Задание 4. Диаграмма последовательности (sequence).drawio
├── Задание_5_JSON_запрос.json
├── Задание_5_JSON_запрос_исправленный.json
└── Задание_5_описание_ошибок.md
```

## Важно

- Всего **4 итерации** на получение зачёта по первой части (задания 1–4).
- Задание 5 входит в **финальный пакет** и сдаётся вместе с доработанными заданиями 1–4.
- Ссылка на папку вставляется в **соответствующее поле урока** на платформе Практикума.
