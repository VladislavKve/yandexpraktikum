# Задание 5. Исправление ошибок в JSON-файле

## Что сделать

1. **Скопировать JSON с платформы**
   - Открой [урок «Работа над проектом. Задание 5»](https://practicum.yandex.ru/trainer/mcrpo-integration-software/lesson/05d19e8f-f88e-46ae-9a63-2f97b77b618e/)
   - Прокрути до блока «Задание 5. Исправление ошибок в JSON-файле»
   - Нажми **«Скопировать код»**
   - Вставь скопированный JSON в файл `Задание_5_JSON_запрос.json` в этой папке

2. **Готово.** JSON проанализирован: найдено 3 ошибки (shop_id→store_id, status "active"→"в работе", category_id string→int). Исправленный вариант: `Задание_5_JSON_запрос_исправленный.json`. Описание: `Задание_5_описание_ошибок.md`.

## Эталон (из урока)

Таблицы ER: `users`, `shops`, `tasks`, `task_assignments`, `specialists`, `contracts`, `task_status_history`, `recruitment_requests`.

Соответствие в ER-диаграмме проекта:
- shops → Store (store_id, name, address)
- users → User (user_id, full_name, email, role, store_id)
- tasks → ServiceTask (task_id, store_id, created_by, work_name, start_date, end_date, status)
- specialists → Specialist (specialist_id, full_name, category_id, availability_status)
- recruitment_requests → RecruitmentRequest (request_id, task_id, status, created_at)

## Критерии

- Найти не менее 3 ошибок в структуре и содержании запроса
- Написать корректный запрос
