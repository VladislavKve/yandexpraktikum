# Удалённый вызов процедур (RPC/RPI) и основы API

## Удалённый вызов процедур (Remote Procedure Invocation)
Стиль взаимодействия, при котором одно приложение (**клиент**) обращается к другому (**сервису**) для выполнения определенных действий.

### Структура взаимодействия
1.  **Запрос (Request)**: Обращение клиента к сервису (например, «дай список заказов»).
2.  **Обработка (Processing)**: Действия сервиса для подготовки ответа.
3.  **Ответ (Response)**: Информация, возвращаемая сервисом клиенту.

## Что такое API (Application Programming Interface)
Это набор правил и контрактов, по которым разные программы взаимодействуют друг с другом. API позволяет использовать функциональность сторонних сервисов (например, Яндекс Карты) без необходимости их разработки с нуля.

### Состав API
*   **Точка входа (Endpoint)**: Адрес, по которому доступен ресурс.
*   **Методы**: Действия, которые можно совершить (GET, POST и т.д.).
*   **Параметры**: Дополнительные данные для уточнения запроса.
*   **Формат данных**: JSON, XML и др.
