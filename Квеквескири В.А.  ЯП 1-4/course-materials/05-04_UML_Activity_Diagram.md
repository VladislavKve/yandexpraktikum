# Диаграмма деятельности (UML Activity Diagram)
**Источник:** Яндекс Практикум | Спринт 5 | Тема 1 | Урок 4

## Сравнение BPMN и UML Activity
- **BPMN**: Чаще используется для бизнес-процессов (взаимодействие людей).
- **UML Activity**: Чаще используется для системных процессов (логика работы системы).

## Основные элементы
1. **Действия**: Прямоугольники со скруглёнными углами.
2. **Потоки**: Однонаправленные стрелки.
3. **Разветвитель/Синхронизатор**: Жирная линия для параллельных потоков.
4. **События**:
   - **Начальное состояние**: Сплошной круг.
   - **Конечное состояние**: Круг с точкой внутри ("бычий глаз").
   - **Конец потока**: Круг с крестиком (завершает только одну ветку, не весь процесс).
5. **Точка принятия решения (Decision)**: Ромб. Выходящие потоки должны иметь условия в квадратных скобках `[условие]`.
6. **Зоны ответственности (Swimlanes)**: Вертикальные или горизонтальные дорожки для разделения участников.

## Рекомендации для проекта
- Используйте UML Activity для детализации системных алгоритмов, если BPMN кажется слишком перегруженным для описания API-вызовов.
- Обязательно указывайте условия на выходах из ромбов принятия решений.
