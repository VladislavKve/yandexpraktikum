# Словарь данных (Data Dictionary)

Словарь данных — это набор определений элементов данных, относящихся к предметной области. Он дополняет ER-диаграмму, предоставляя детальную информацию об атрибутах.

## Зачем нужен словарь данных
1.  **Единообразие:** Помогает команде одинаково понимать формат и содержание данных.
2.  **Детализация:** Описывает типы данных, ограничения и допустимые значения, которые сложно отобразить на диаграмме.
3.  **Основа для разработки:** Служит ТЗ для разработчиков БД.

## Состав словаря данных
Обычно словарь данных представляется в виде таблицы со следующими колонками:
- **Сущность:** К какой таблице относится атрибут.
- **Атрибут:** Название поля (на логическом и физическом уровнях).
- **Описание:** Смысловое значение поля.
- **Тип данных:** Например, String, Integer, Boolean, Date.
- **Обязательность (Null/Not Null):** Может ли поле быть пустым.
- **Ограничения (Constraints):** Например, уникальность, диапазон значений, формат (email, телефон).
- **Пример значения:** Для наглядности.
