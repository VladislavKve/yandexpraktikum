# Ветвление
**Спринт 10/13 | Тема 1/4: Система контроля версий Git и парадигмы разработки | Урок 3/4**

Из прошлого урока вы узнали о подходах Git Flow и Trunk-Based Development. В этом уроке — практика работы с ветками.

## Управление ветками

### Команда git branch
- Просмотр веток, создание новых веток.
- `git branch --show-current` — показать текущую ветку.
- Другие опции для просмотра списка веток.

### Команда git switch
Современная команда для переключения между ветками.
- `git switch my-branch` — перейти на ветку `my-branch`.
- `git switch -` или `git switch --previous` — вернуться на предыдущую ветку (удобно при временном переключении, например для push в удалённый репозиторий).

**Осторожно:** при несохранённых (uncommitted) изменениях переключение не выполнится. Опция `--discard-changes` принудительно отбрасывает изменения — использовать с осторожностью, лучше сначала закоммитить.

### Команда git checkout
Историческая команда для переключения веток и других операций. Для смены ветки предпочтительнее `git switch`.

### Удаление веток
- `git branch -d` — удалить ветку (если она слита).
- `git branch -D` — принудительное удаление.

### Создание ветки
- `-c` — создать ветку от текущего состояния.
- `-b` — создать ветку и переключиться на неё.

## Итоги
Ветвление — основа работы с Git. Используйте `git switch` для переключения, `git branch` для просмотра и создания веток.
