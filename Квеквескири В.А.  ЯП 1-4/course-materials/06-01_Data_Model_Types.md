# Виды моделей данных

## Что такое модель данных
**Модель данных (Data Model)** — это представление предметной области в виде понятий и связей между ними.
`Модель данных = Понятия + Связи между понятиями`

## Виды моделей данных
1. **Концептуальная модель** — описывает основные понятия предметной области и связи между ними без привязки к технической реализации. Понятна заказчику.
2. **Логическая модель** — детализирует концептуальную модель, добавляя атрибуты, типы данных и уточняя связи. Не зависит от конкретной СУБД.
3. **Физическая модель** — описывает структуру данных для конкретной СУБД (таблицы, колонки, индексы, ключи).

## Ключевые элементы
- **Сущность (Entity)** — объект предметной области (например, "Клиент", "Заказ").
- **Атрибут (Attribute)** — характеристика сущности (например, "Имя клиента", "Дата заказа").
- **Связь (Relationship)** — логическая зависимость между сущностями.
