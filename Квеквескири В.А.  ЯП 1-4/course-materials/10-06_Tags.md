# Работа с тегами (Tags)
**Спринт 10/13 | Тема 2/4: Продвинутая работа с удалёнными репозиториями и тегами | Урок 2/3**

Теги в Git — инструмент управления версиями проектов. Позволяют отмечать важные моменты в истории: релизы или значимые изменения.

## Что такое тег
- **Неизменяемость** — теги фиксируют конкретный коммит и не изменяются. Удобно ссылаться на версию (v1.0, v2.0-beta).
- **Читаемость** — понятные имена: release-2023-10, test-5.4.0.
- **Управление версиями** — отслеживание релизов, откат к предыдущим версиям.
- **Важные моменты** — завершение фазы разработки, начало тестирования, выпуск новой функции.
- **CI/CD** — указатель на коммит для автоматизации сборки и развёртывания.
- **Документация** — быстрый поиск версий и понимание изменений.

## Виды тегов

### Легковесные (lightweight)
Простой указатель на коммит: `git tag <имя>`.

### Аннотированные (annotated)
С метаданными и сообщением:
- `git tag -a <имя> -m "<сообщение>"` — создать с сообщением
- `git tag -a <имя> -m "<сообщение>" <хеш>` — на конкретный коммит
- Флаги: `-a`/`--annotate`, `-m` (если не указать — откроется редактор)
- Хеш коммита можно указать не полностью, если он однозначен

## Конфликт имён (тег и ветка)
- **Ясное именование** — префиксы: v1.0 для тегов, feature/my-feature для веток.
- **Проверка** — смотреть существующие объекты перед созданием.
- **Полные ссылки** — `refs/tags/<имя>` при необходимости.

## Работа с тегами

### Просмотр тегов
`git tag` — список всех тегов в репозитории.

### Удаление тегов
- Локально: `git tag -d <имя>`
- В удалённом репозитории: `git push <remote> --delete refs/tags/<имя>`

### Отправка тегов
`git push [опции] [remote] [тег]` — отправить тег в remote.
- `git push origin <тег>` — один тег
- `git push origin --tags` — все теги

### Редактирование тегов
`git tag -a -f <имя> -m "msg"` — флаг `-f` перезаписывает существующий тег (аналог `push --force`).

### Переключение на тег
`git checkout <тег>` или `git switch --detach <тег>` — перейти в состояние detached HEAD на коммит, на который указывает тег.

## Тесты (ответы)
**Соответствие команд и действий:**
| Действие | Команда |
|----------|---------|
| Убрать тег yandex в remote yandex | `git push yandex --delete refs/tags/yandex` |
| Добавить аннотированный тег yandex с сообщением | `git tag -a yandex -m "Тема 6. Урок 2"` |
| Добавить легковесный тег yandex | `git tag yandex` |
| Просмотр деталей тега | `git show yandex` |

**Тип тега по выводу git show:** если есть строка `Tagger: ...` — аннотированный; если только коммит — легковесный.

## Сводка команд
- `git tag` — список тегов
- `git tag <имя>` — создать легковесный тег
- `git tag -a <имя> -m "msg"` — аннотированный тег
- `git tag -d <имя>` — удалить локально
- `git push origin <тег>` или `git push origin --tags` — отправить в remote
