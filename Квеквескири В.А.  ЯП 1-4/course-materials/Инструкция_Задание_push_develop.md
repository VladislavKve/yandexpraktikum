# Задание: отправка ветки develop в несколько удалённых репозиториев

**Формулировка:** Напишите команду отправки изменений в ветке develop в уже добавленные удалённые репозитории main, origin, test, stage.

---

## Правильный ответ

Введите в редактор кода **четыре команды** (каждую с новой строки):

```
git push main develop
git push origin develop
git push test develop
git push stage develop
```

---

## Пошаговая инструкция

### Шаг 1. Убедитесь, что вы на ветке develop
```bash
git branch --show-current
```
Должно вывести `develop`. Если вы на другой ветке:
```bash
git switch develop
```

### Шаг 2. Проверьте, что все удалённые репозитории добавлены
```bash
git remote -v
```
Должны быть видны: main, origin, test, stage с их URL.

### Шаг 3. Отправьте ветку develop в каждый remote
Выполните по очереди (или скопируйте все четыре строки):

```bash
git push main develop
git push origin develop
git push test develop
git push stage develop
```

### Шаг 4. Альтернатива: цикл в bash (для терминала)
Если нужно выполнить в своём терминале одной командой:
```bash
for remote in main origin test stage; do git push $remote develop; done
```

### Шаг 5. Проверка
После отправки проверьте, что ветка develop есть на каждом remote:
```bash
git push main develop   # проверит main
git ls-remote main      # покажет ветки на main
```
или зайдите в веб-интерфейс каждого репозитория.

---

## Пояснение

- `git push <remote> <branch>` — отправляет указанную ветку в указанный удалённый репозиторий.
- У Git нет одной команды «отправить во все remote сразу» — нужно вызывать `git push` для каждого.
- Порядок remote (main, origin, test, stage) может быть любым — главное, отправить в каждый.
