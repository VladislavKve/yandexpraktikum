# Переход от логической ER-модели к физической

Физическая ER-модель описывает структуру будущей базы данных в конкретной СУБД. На этом уровне сущности становятся таблицами, а атрибуты — полями.

## 5 шагов перехода
1.  **Преобразовать сущности в таблицы:** Названия переводятся на английский язык и приводятся к формату СУБД (например, `users`, `orders`).
2.  **Преобразовать атрибуты в поля:** Атрибуты становятся колонками таблиц с указанием типов данных.
3.  **Добавить первичные ключи (Primary Keys):** Определение уникального идентификатора для каждой таблицы.
4.  **Добавить внешние ключи (Foreign Keys):** Реализация связей между таблицами через ссылки на первичные ключи других таблиц.
5.  **Добавить системные таблицы и поля:** Например, поля `created_at`, `updated_at`, `is_deleted`.

## Соответствие элементов
| Логический уровень | Физический уровень |
| :--- | :--- |
| Сущность | Таблица (Table) |
| Атрибут | Поле / Колонка (Field / Column) |
| Связь | Внешний ключ (Foreign Key) |
| Первичный ключ | Первичный ключ (Primary Key) |
