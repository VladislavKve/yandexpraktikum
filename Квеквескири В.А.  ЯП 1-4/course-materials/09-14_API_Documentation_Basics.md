# Документирование API

## Что такое документация API
Это описание того, как работает API и как его использовать. Она необходима для взаимодействия разработчиков, тестировщиков, архитекторов и аналитиков.

## Виды документации
*   **Непубличная:** Для внутреннего использования в компании.
*   **Публичная:** Для внешних разработчиков (например, Telegram API).

## Форматы документирования
1.  **Текстовый:** Confluence, Google Docs, текстовые редакторы. Минус — сложность поддержания актуальности.
2.  **Специальные форматы (Спецификации):**
    *   **Swagger (OpenAPI Specification):** Самый популярный инструмент для REST API. Позволяет генерировать интерактивную документацию.
    *   **WSDL:** Для SOAP API.

## Инструменты
*   **Swagger:** Визуализация и тестирование REST API.
*   **Postman:** Инструмент для отправки запросов и тестирования API.
*   **Redoc:** Генерация статической документации из OpenAPI.
