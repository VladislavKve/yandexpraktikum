# Элементы SOAP API

## Структура SOAP-сообщения
SOAP-сообщение — это XML-документ, называемый **SOAP Envelope (конверт)**. Он состоит из двух основных частей:
1.  **SOAP Header (заголовок):** Необязательная часть. Содержит служебную информацию (авторизация, цифровая подпись, правила обработки).
2.  **SOAP Body (тело):** Обязательная часть. Содержит фактические данные запроса или ответа.
    *   **soap:Fault:** Элемент внутри тела для передачи информации об ошибках.

## Пример SOAP-запроса
```xml
<?xml version="1.0"?>
<soap:Envelope xmlns:soap="http://www.w3.org/2003/05/soap-envelope/" xmlns:m="http://www.example.org/stock">
  <soap:Body>
    <m:GetPrice>
      <m:Item>12345</m:Item>
    </m:GetPrice>
  </soap:Body>
</soap:Envelope>
```

## Особенности SOAP
*   **Протоколы:** Чаще всего HTTP, но может работать через SMTP, FTP и др.
*   **Стиль представления:** Только XML.
*   **Стандартизация:** Строгие правила формирования сообщений, описанные в WSDL.
