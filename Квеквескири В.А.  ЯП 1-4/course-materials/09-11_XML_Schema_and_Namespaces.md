# XML-схема и пространства имен

## Пространства имен (Namespaces)
Используются для предотвращения конфликтов имен элементов.
*   **Декларация:** `xmlns:prefix="URI"`
*   **Префикс:** Короткий псевдоним для пространства имен, добавляется к тегам.
    *   *Пример:* `<a:plant xmlns:a="http://example.org/flower">`

## XML-схема (XSD)
**XSD (XML Schema Definition)** — язык описания структуры XML-документа.
*   **Назначение:** Определение правил (типы данных, обязательность элементов, вложенность) для автоматической валидации.
*   **Contract First:** Подход, при котором сначала согласуется схема (контракт), а затем ведется разработка.

## Основные типы данных в XSD
*   `xs:string` — строка.
*   `xs:decimal`, `xs:integer` — числа.
*   `xs:boolean` — логический тип.
*   `xs:date`, `xs:time` — дата и время.
