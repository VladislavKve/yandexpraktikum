# Параметры HTTP-запроса и ответа

## Виды параметров запроса
1. **Path Parameters (в URL):** Часть пути, используется для идентификации конкретного ресурса.
    *   *Пример:* `GET /items/123`
2. **Query Parameters (в URL после ?):** Используются для фильтрации, поиска, сортировки и пагинации.
    *   *Пример:* `GET /items?search=glass&sort=price`
3. **Header Parameters (в заголовках):** Техническая информация (авторизация, тип контента).
4. **Body Parameters (в теле):** Данные для создания или обновления ресурса (обычно JSON).

## Параметры ответа
*   **Status Code:** Результат обработки.
*   **Headers:** Формат данных, время ответа, сервер.
*   **Body:** Запрошенные данные или описание ошибки.
