# Диаграмма бизнес-процесса (BPMN)
**Источник:** Яндекс Практикум | Спринт 5 | Тема 1 | Урок 3

## Основные понятия
**BPMN (Business Process Model and Notation)** — нотация для моделирования бизнес-процессов. Позволяет разделить зоны ответственности и показать переход действий между участниками.

## Элементы нотации
1. **Пул (pool) и дорожки (swimlane)**:
   - **Пул** — организация или группа участников (например, "Сеть магазинов").
   - **Дорожка** — конкретная роль (например, "Управляющий магазином", "Специалист HR").
   
2. **Задачи (task) и подпроцессы (sub-process)**:
   - **Прямоугольник** — простая задача.
   - **Прямоугольник с [+]** — подпроцесс (имеет свою отдельную модель).
   - **Круговая стрелка** — циклическое действие.
   - **Три штриха (|||)** — экземпляры действия (параллельные или последовательные).

3. **События (events)**:
   - **Тонкий круг** — Стартовое событие.
   - **Жирный круг** — Конечное событие.
   - **Двойной тонкий круг** — Промежуточное событие.

4. **Шлюзы (gateways)**:
   - **X (Exclusive)** — Исключающее "ИЛИ". Только один путь.
   - **+ (Parallel)** — Параллельное "И". Все пути выполняются одновременно.
   - **O (Inclusive)** — Неисключающее "ИЛИ". Один или несколько путей.

## Важные правила для проекта
- Процесс должен иметь логическое завершение для всех веток.
- Если специалист не найден, процесс не может просто оборваться на "добавлении в базу" — должен быть возврат к поиску или уведомление заказчика.
- Имена задач должны начинаться с глагола (например, "Создать заявку").
