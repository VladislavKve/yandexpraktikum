# Сетевые модели и компьютерные протоколы

## Сетевые модели
Сетевые модели описывают наборы протоколов, которым должны соответствовать аппаратное и программное обеспечение для совместимости в сети.

### Основные модели:
1. **OSI (Open Systems Interconnection)** — эталонная семиуровневая модель (ISO). В реальном мире в чистом виде не встречается, используется для понимания устройства сетей.
2. **TCP/IP (Transmission Control Protocol/Internet Protocol)** — основная модель интернета.

## Сетевая модель TCP/IP
Названа в честь двух ключевых протоколов:
*   **IP (Internet Protocol)** — определяет адрес устройства и маршруты доставки. Не гарантирует целостность (ненадёжный).
*   **TCP (Transmission Control Protocol)** — протокол управления передачей. Работает поверх IP, обеспечивая надёжность.

### Уровни TCP/IP:
1. **Прикладной (Application)** — взаимодействие приложений (HTTP, FTP, SMTP).
2. **Транспортный (Transport)** — передача данных между процессами (TCP, UDP).
3. **Сетевой (Internet)** — маршрутизация пакетов (IP).
4. **Канальный / Физический (Network Access)** — передача данных по физическим каналам.
