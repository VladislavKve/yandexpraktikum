# HTTP-запрос и ресурсы

## Ресурсы (Resources)
Ресурс — это цифровая абстракция объекта (человека, предмета, процесса). 
*   Имеет уникальный идентификатор (URI/URL).
*   Может содержать другие ресурсы (модель ресурсов).
*   Является основной единицей передачи информации в HTTP.

## Сериализация и десериализация
*   **Сериализация** — преобразование ресурса в представление (JSON, XML) для передачи.
*   **Десериализация** — обратный процесс преобразования представления в ресурс.

## Структура HTTP-запроса
1. **Стартовая строка (Start line):**
    *   Метод (GET, POST, PUT, DELETE и др.).
    *   Путь к ресурсу (URI).
    *   Версия протокола (HTTP/1.1, HTTP/2).
2. **Заголовки (Headers):** Метаданные (тип контента, авторизация и т.д.).
3. **Тело запроса (Body):** Сами данные (необязательно для GET).
