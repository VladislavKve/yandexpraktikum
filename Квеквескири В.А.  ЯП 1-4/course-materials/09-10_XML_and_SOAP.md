# Стили представления данных: XML и SOAP

## Что такое SOAP
**SOAP (Simple Object Access Protocol)** — фреймворк обмена сообщениями, использующий XML. Популярен в банковской и телекоммуникационной сферах из-за жесткой структуры данных.

## Что такое XML
**XML (eXtensible Markup Language)** — расширяемый язык разметки. Имеет древовидную структуру и использует теги для описания данных.

## Основные элементы XML
1.  **Теги:** Обозначаются угловыми скобками `<tag>`. Должны быть открывающими и закрывающими.
2.  **Атрибуты:** Дополнительная информация внутри тега.
    *   *Пример:* `<title lang="ru">`
3.  **Вложенность:** Теги могут содержать другие теги.

## Пример XML
```xml
<book>
  <author>Рэй Далио</author>
  <title lang="ru">Принципы. Жизнь и работа.</title>
  <price currency="RUB">2100</price>
</book>
```
