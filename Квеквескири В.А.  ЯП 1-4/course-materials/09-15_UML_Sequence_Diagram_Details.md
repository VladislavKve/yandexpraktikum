# Диаграмма последовательности (UML Sequence Diagram)

## Определение
Диаграмма последовательности показывает взаимодействие объектов во времени. Акцент делается на порядке обмена сообщениями.
*   **Горизонтальная ось:** Объекты и акторы.
*   **Вертикальная ось:** Время (сверху вниз).

## Основные элементы
1.  **Акторы (Actors):** Внешние участники (люди или системы). Изображаются в виде человечка.
2.  **Объекты (Objects):** Участники внутри системы. Изображаются в виде прямоугольников.
3.  **Линии жизни (Lifelines):** Пунктирные линии под объектами, показывающие время их существования.
4.  **Фокус управления (Execution specification):** Узкие прямоугольники на линиях жизни, показывающие период активности объекта.
5.  **Сообщения (Messages):**
    *   **Синхронные (Сплошная линия с закрашенной стрелкой):** Отправитель ждет ответа.
    *   **Асинхронные (Сплошная линия с открытой стрелкой):** Отправитель не ждет ответа.
    *   **Ответные (Пунктирная линия со стрелкой):** Возврат данных.

## Фреймы (Frames)
Используются для логических конструкций:
*   **alt:** Альтернатива (if-else).
*   **opt:** Опциональное действие (if).
*   **loop:** Цикл.
*   **ref:** Ссылка на другую диаграмму.

## Рекомендации по проектированию
*   Имена объектов должны быть конкретными (например, `API Gateway`, `Auth Service`, а не просто `System`).
*   Соблюдайте иерархию вызовов: UI -> API -> Backend -> DB.
