# Обмен сообщениями (Messaging)

## Основные понятия
*   **MOM (Message-Oriented Middleware)**: Промежуточное ПО (система обмена сообщениями), которое гарантирует доставку сообщений даже при сбоях в сети.
*   **Сообщение (Message)**: Неделимая единица данных. Состоит из **заголовка** (метаданные для доставки) и **тела** (полезная нагрузка).
*   **Канал (Channel)**: Виртуальная «труба», соединяющая отправителя и получателя.

## Процесс доставки
1.  **Создание**: Отправитель формирует сообщение.
2.  **Отправка**: Отправитель помещает сообщение в канал.
3.  **Доставка**: Система MOM передает сообщение с промежуточным хранением (store-and-forward).
4.  **Получение**: Получатель извлекает сообщение из канала.
5.  **Обработка**: Получатель извлекает данные из сообщения.

## Преимущества
*   **Асинхронность**: Отправитель не ждет завершения обработки сообщения получателем.
*   **Надежность**: Гарантированная доставка через промежуточное хранение.
*   **Низкая связанность**: Приложения не знают друг о друге напрямую, только о каналах и форматах сообщений.
