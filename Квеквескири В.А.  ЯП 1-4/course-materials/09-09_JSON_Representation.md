# Стили представления данных: JSON

## Что такое JSON
**JSON (JavaScript Object Notation)** — самый популярный текстовый формат обмена данными. Он прост для чтения человеком и легко обрабатывается машинами.

## Основные правила синтаксиса
1.  **Объект:** Заключается в фигурные скобки `{ }`.
2.  **Пара «ключ — значение»:** Ключ всегда в двойных кавычках, отделяется от значения двоеточием.
    *   *Пример:* `"name": "Ivan"`
3.  **Разделитель:** Пары разделяются запятыми.
4.  **Типы данных:**
    *   **String (Строка):** В двойных кавычках.
    *   **Number (Число):** Без кавычек.
    *   **Boolean (Логический):** `true` или `false`.
    *   **Array (Массив):** В квадратных скобках `[ ]`.
    *   **Null:** Пустое значение.
    *   **Object:** Вложенный объект.

## Пример JSON
```json
{
  "id": 1,
  "name": "Бокал",
  "properties": {
    "material": "стекло",
    "volume": 300
  },
  "tags": ["посуда", "хрупкое"]
}
```
