# HTTP-ответ

## Структура HTTP-ответа
1. **Код состояния (Status Code):** Трёхзначное число, сообщающее результат.
2. **Заголовки (Headers):** Метаданные ответа.
3. **Тело (Body):** Данные, возвращаемые сервером.

## Группы кодов состояния
*   **1xx:** Информационные (предварительный ответ).
*   **2xx:** Успех (запрос успешно обработан).
*   **3xx:** Перенаправление (нужен другой запрос).
*   **4xx:** Ошибка клиента (неверный запрос, ресурс не найден).
*   **5xx:** Ошибка сервера (проблема на стороне сервиса).

### Примеры:
*   **200 OK:** Успех.
*   **404 Not Found:** Ресурс не найден.
*   **500 Internal Server Error:** Внутренняя ошибка сервера.
