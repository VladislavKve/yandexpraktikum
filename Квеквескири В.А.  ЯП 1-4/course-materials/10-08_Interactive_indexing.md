## Разбиение на микрокоммиты

**Микрокоммиты** — небольшие, но тематически целостные коммиты. Имеются в виду не минимально возможные коммиты, а такие, которые содержат необходимый и достаточный набор изменений, сгруппированных по смыслу.

**Зачем разбивать:**
- **Упростить ревью кода** — каждый коммит отражает одну небольшую часть изменений.
- **Облегчить откат** — легко найти и откатить отдельные правки.
- **Улучшить поиск ошибок** — проще найти, в каком именно коммите была допущена ошибка.

## Интерактивное индексирование

Команда `git add -p` (или `--patch`) позволяет добавлять изменения по фрагментам (hunks):

| Клавиша | Действие |
|---------|----------|
| **y**  | добавить фрагмент в индекс |
| **n**  | пропустить фрагмент |
| **s**  | разделить фрагмент на более мелкие части |
| **e**  | отредактировать фрагмент вручную |
| **q**  | выйти из режима без дальнейших изменений |

## Практика (тест)

**Вопрос:** Что такое интерактивное индексирование?

**Варианты:**
- Метод добавления всех изменений в индекс
- **Способ добавления только выбранных изменений в индекс для создания более осмысленных коммитов** ✓
- Команда для просмотра истории коммитов

**Вопрос 2:** Какой вариант выбрать при использовании `git add -p`, чтобы пропустить фрагмент изменений?

**Варианты:** y / **n** ✓ / e / q  
Правильный ответ: **n** (пропустить фрагмент)
