# Припрятывание и очистка
**Спринт 10/13 | Тема 3/4: Продвинутая работа с коммитами | Урок 2/4**

## Зачем нужно

Сценарий: вы активно разрабатываете код, но вас попросили переключиться на срочную задачу. Не хочется терять изменения и рано коммитить — их припрятывают.

## git stash

**Припрятывание** — временное сохранение изменений (рабочая директория + индекс) в стек `refs/stash`.

### Команды

| Команда | Действие |
|---------|----------|
| `git stash` / `git stash push` | Припрятать изменения |
| `git stash push -m "описание"` | Припрятать с сообщением |
| `git stash list` | Список припрятанного (stash@{0}, stash@{1}...) |
| `git stash apply` | Применить последнее (запись остаётся) |
| `git stash apply stash@{n}` | Применить конкретную запись |
| `git stash apply --index` | Восстановить также индекс |
| `git stash pop` | Применить и удалить из стека |
| `git stash drop stash@{n}` | Удалить запись из стека |

### Заметка

`git stash save` устарел, рекомендуется `git stash push`. По умолчанию stash не включает неотслеживаемые файлы; `-u` / `--include-untracked` добавит их.

## git clean

**Очистка** — удаление неотслеживаемых файлов (временные, артефакты сборки). **Удалённое нельзя восстановить через Git!**

| Флаг | Действие |
|------|----------|
| `-n` / `--dry-run` | Показать, что будет удалено (без удаления) |
| `-f` | Выполнить удаление |
| `-d` | Удалять и директории |
| `-x` | Удалять даже игнорируемые файлы |

**Безопасный порядок:** сначала `git clean -n`, затем `git clean -f`.

## Практика

**Восстановление:** `git stash apply` — восстановить, оставив в списке; `git stash pop` — восстановить и удалить из списка (аналогия с очередью).

**Очистка припрятываний:** `git stash drop` — удалить последнее; `git stash drop stash@{1}` — удалить конкретное; `git stash pop` — применить и удалить.

**Тест 1:** какая команда восстанавливает и удаляет из списка? → `git stash pop`  
**Тест 2:** в каком случае рекомендуется `git stash`, а не временный коммит? → когда изменения черновые и их потеря не представляет риска

**Практика (IDE):** создать репозиторий, файл, коммит; внести изменения; `git stash save "МоиИзменения"`; `git stash list`; `git stash apply`; `git stash drop`.
