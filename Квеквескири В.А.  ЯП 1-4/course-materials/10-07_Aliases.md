# Псевдонимы (Aliases)
**Спринт 10/13 | Тема 2/4: Продвинутая работа с удалёнными репозиториями и тегами и псевдонимы | Урок 3/3**

Псевдонимы (aliases) — сокращения для команд Git. Позволяют задавать свои команды вместо одной или нескольких стандартных. Удобны для частых команд — экономят время и уменьшают ошибки ввода.

## Зачем нужны
- **Упрощение команд** — длинные команды с опциями сокращаются до нескольких символов.
- **Снижение ошибок** — меньше символов → меньше опечаток.
- **Персонализация** — настройка под свои привычки.
- **Читаемость** — интуитивные имена для рабочей логики.

## Работа с псевдонимами

### Создание
`git config --global alias.<имя> <команда>`
- `<имя>` — короткое имя (например, `st`, `lg`).
- `<команда>` — команда Git (push, status), строка с командами (в одинарных кавычках) или внешняя команда.

**Примеры:**
```bash
git config --global alias.st status
git config --global alias.lg "log --oneline --graph"
git config --global alias.co checkout
```

### Просмотр
`git config --get-regexp alias` — список всех псевдонимов.

### Редактирование
Изменить в файле `~/.gitconfig` в секции `[alias]` или задать заново через `git config`.

### Удаление
`git config --global --unset alias.<имя>`

Пример: `git config --global --unset alias.lg` — удаляет псевдоним `lg`.

## Практика: исправление синтаксиса

**Задание:** В команде по добавлению глобального псевдонима `lg` допущены синтаксические ошибки. Исправьте их.

**Неправильно:** `git alias lg = log --oneline --graph`

**Правильно:** `git config --global alias.lg "log --oneline --graph"`

**Ошибки:** не хватает `config --global`; вместо `alias lg =` нужно `alias.lg`; значение команды берётся в кавычки.
