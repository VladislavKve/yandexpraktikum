# Перезапись истории (разбиение и схлопывание коммитов)
**Спринт 10/13 | Тема 3/4: Продвинутая работа с коммитами | Урок 4/4**

## Разбиение коммита на несколько

1. **Интерактивный ребейз** на коммит перед разбиваемым:
   ```bash
   git rebase -i <хеш_коммита_до_разбиваемого>
   ```
   Git откроет редактор со списком коммитов (pick, edit, squash и т.д.).

2. **Меняем метку** разбиваемого коммита с `pick` на `edit`. Сохраняем (`:wq` в vim).

3. **Откат к родительскому** (изменения остаются в рабочей директории):
   ```bash
   git reset HEAD^
   ```

4. **Группируем и коммитим** несколько раз:
   ```bash
   git add <файлы>
   git commit -m "Первый логический блок"
   git add ...
   git commit -m "Второй блок"
   ```

5. **Продолжить ребейз:**
   ```bash
   git rebase --continue
   ```

## Схлопывание коммитов в один

1. **Интерактивный ребейз** на коммит перед первым объединяемым:
   ```bash
   git rebase -i <хеш_коммита_до_первого_объединяемого>
   ```

2. **В редакторе** меняем `pick` на `squash` (или `s`) для коммитов, которые нужно объединить.

3. Git схлопнет коммиты в один, предложит отредактировать сообщение, затем `git rebase --continue`.

## Тесты

1. **Разбиение коммита** → метка **edit**
2. **Схлопывание коммитов** → метка **squash**
